# quake-engine (working name)

A new game engine in Rust, using id Software's original Quake as a fixture to build and test against.

There's nothing to run yet. The project is in research.

- [DESIGN.md](DESIGN.md): the founding principles and workflow.
- [docs/README.md](docs/README.md): all technical documentation.

The engine loads game data from your own copy of Quake. Original game data is never committed to this repository.
