# Proposal 0141: Vulkan 1.3

Status: accepted and implemented, 2026-11-06.

## Research

Skinning needs a barrier between a compute pass and drawing. `vulkane`'s clear one, `memory_barrier2`, is from Vulkan 1.3, and the engine asked for 1.1. The human's word on that: it sounds like something that needs upgrading.

What 1.3 asks of a player's machine, from what could be found:

- **NVIDIA:** [from Maxwell on](https://www.collabora.com/news-and-blog/news-and-events/nvk-enabled-for-maxwell,-pascal,-and-volta-gpus.html), which is the GTX 900 series, from 2014. That source is about the open driver, and says Kepler lacks what 1.3 needs. What NVIDIA's own driver does for Kepler wasn't confirmed.
- **AMD:** [Vega and RDNA](https://www.tweaktown.com/news/89149/amds-next-gen-radeon-rx-7000-rdna-3-gpus-get-vulcan-1-support/index.html). Older GCN cards weren't confirmed either way.
- **Intel:** [UHD and Iris Xe, then Arc](https://www.techpowerup.com/295824/intel-arc-alchemist-gpus-get-vulkan-1-3-compatibility?amp).

These are news pieces from around 2022, not Khronos's own list. Nothing reliable turned up on 1.4. This machine's GTX 1070 reports 1.4.312.

## Design

- **The engine asks for 1.3,** with `synchronization2` on.
- **A device under 1.3 isn't picked.** If that's all there is, it says which card, what it has, and what's needed. That's a different failure from having no device at all.
- **New code uses the 1.3 barriers.** Existing ones stay. They're still valid in 1.3, and rewriting working code would only risk it.

## Proposal

- **Selected approach:** the above.
- **Tradeoffs:** cards older than the list above can't run the engine. For a new engine that's a fair floor. 1.4 isn't needed by anything yet.
- **Acceptance criteria:** the game and its GPU tests run on 1.3, and a card that's too old is told so by name.
- **Future extension:** dynamic rendering, in place of render passes, if it ever earns the rewrite.

## Review

The game and every GPU test ran on 1.3 with no change to what they draw.

That a real card under 1.3 gets the message hasn't been tried, as none is here. The check of the version has a test, and the wording was only read. **Whether it behaves on an old card needs a person with one.**
