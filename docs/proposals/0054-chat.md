# Proposal 0054: chat

Status: accepted, 2026-11-04, increment 9.

## Research

- `Key_Message` takes keys for a line of chat while the game goes on, and `Con_DrawNotify` draws it under the recent lines, as `say:` and a cursor.
- `Host_Say` passes a line on with a mark as its first character, and `Con_Print` turns that into bright text and `misc/talk.wav`.
- `say_team` reaches only players with the same team, and only under `teamplay`. A player's team comes from their pants colour.
- `default.cfg` in the game data already binds `t` to `messagemode`.

## Design

- `ConsoleView` holds a line of chat apart from the console's own input, and `chat_key` takes keys for it. Enter says it, Escape forgets it, and the view stays clear.
- `messagemode` and `messagemode2` start a line for everyone or for the team. Leaving the game forgets it, so keys can't stay caught.
- The line goes through the console in quotes, so a `;` stays in it. A typed quote becomes an apostrophe, because it would end the line.
- The server marks what's said with `TALK_MARK`, drops control characters and keeps 128 characters, so nothing typed can pass as talk or as a second line.

## Proposal

- **Selected approach:** the above.
- **Tradeoffs:** a line can be 96 characters, against the original's 31, and it scrolls as it's typed. Mouse look and held keys carry on while typing, as in the original.
- **Acceptance criteria:** tests cover a line said, team talk under `teamplay` and without it, Escape, nothing typed, a quote, a line longer than the screen, and control characters. A capture of two real processes shows the line and bright text.
- **Future extension:** none planned.
