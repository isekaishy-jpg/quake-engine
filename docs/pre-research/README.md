# Pre-research decisions

These record what we decided to do before adopting the [workflow](../../DESIGN.md#workflow). They set direction, and they aren't research: each item still needs research into how it will actually be done, then a design and a proposal. See the [research plan](../research/plan.md).

Experiments mentioned here were throwaway. Their code wasn't kept, and most used simplified models, so their results are starting evidence.

- [Technology choices](stack.md): the stack, timing, physics, assets, entities and audio
- [Maps](maps.md): map contents, the importer and tooling
- [Networking](networking.md): the model, lag compensation, fair play, projectiles and weapon timing
- [Baseline](baseline.md): which version of Quake is the reference, and how differences were resolved
- [Feature catalog](feature-catalog.md): what the original engine does, by system
- [Reference tables](reference-tables.md): commands, cvars, switches and builtins
- [Source catalog](source-catalog.md): what's in the original source, by file
